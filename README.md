# مرموق · MARMOUQ

> **طريقك لتكون شخصية مرموقة** — متجر إلكتروني مخصص بالكامل (بدون منصات جاهزة) لأزياء «مرموق» الرجالية، مع لوحة تحكم احترافية، جاهز للرفع على **Railway**.

---

## ما الذي يتضمنه المتجر

### واجهة المتجر (للعملاء)
- **الصفحة الرئيسية:** واجهة سينمائية، شريط القيم، أقسام تحريرية، «قصة الألوان» التفاعلية للسويتر، وصل حديثاً، إطلالة الموسم بنقاط تفاعلية، آراء العملاء.
- **المتجر والأقسام** `/shop` مع فلترة باللون والمقاس والسعر والترتيب، وعرض كل لون كبطاقة مستقلة.
- **صفحة المنتج:** معرض صور يتبدّل حسب اللون، اختيار المقاس مع تنبيه «آخر قطعتين»، دليل المقاسات، «اطلب عبر واتساب»، أكمل الإطلالة، منتجات مشابهة، وشريط شراء ثابت على الجوال.
- **الإطلالات** `/looks`: أطقم كاملة بخصم عند شرائها معاً، مع نقاط تفاعلية على الصورة.
- **منسّق الإطلالة** `/atelier`: يركّب العميل طقمه قطعة قطعة (تريكو، قميص، ربطة، بنطال، حذاء) ويشاركه برابط.
- **السلة وإتمام الطلب:** الدفع عند الاستلام أو حوالة/محفظة، كوبونات الخصم، رسوم الشحن حسب المحافظة، والتوصيل المجاني فوق حد معيّن.
- **تأكيد الطلب وتتبعه** `/track`، وإرسال تفاصيل الطلب للمتجر عبر واتساب.
- المفضلة، البحث الفوري، صفحات: قصتنا، تواصل معنا، السياسات، وخريطة الموقع لمحركات البحث.

### لوحة التحكم `/admin`
- **لوحة القيادة:** المبيعات والطلبات ومتوسط الطلب والعملاء الجدد مقارنةً بالفترة السابقة، رسم بياني يومي، الأكثر مبيعاً، والمخزون المنخفض.
- **الطلبات:** تصفية بالحالة، بحث، تغيير الحالة مع إعادة المخزون تلقائياً عند الإلغاء، حالة الدفع، رسائل واتساب جاهزة، فاتورة للطباعة، وتصدير CSV.
- **المنتجات:** محرر كامل للألوان × المقاسات مع المخزون لكل تركيبة، رفع الصور وربطها بالألوان، الأسعار والخصومات، النشر والمسودات والأرشفة، ونسخ المنتج.
- **التصنيفات، الإطلالات** (مع محرر النقاط على الصورة)، **العملاء، الكوبونات، مناطق الشحن**.
- **الإعدادات:** بيانات التواصل وواتساب، نصوص وصورة الواجهة، شريط الإعلانات، طرق الدفع وحسابات التحويل، العملة، السياسات، آراء العملاء.
- **الفريق:** أدوار (مالك / مدير / موظف)، وتنبيه فوري داخل اللوحة عند وصول طلب جديد. تنبيهات تيليجرام اختيارية.

### التقنية
Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · PostgreSQL + Drizzle ORM. الصور تُخزَّن في قاعدة البيانات نفسها بثلاثة مقاسات WebP، فلا تحتاج أي خدمة تخزين إضافية.

## الرفع على Railway (خطوة بخطوة)

1. ادخل [railway.com](https://railway.com) ← **New Project** ← **Deploy from GitHub repo** ← اختر هذا المستودع.
2. داخل المشروع: **+ New** ← **Database** ← **PostgreSQL**.
3. افتح خدمة المتجر ← **Variables** وأضف:

   | المتغير | القيمة |
   |---|---|
   | `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
   | `AUTH_SECRET` | نص عشوائي طويل (32 حرفاً أو أكثر) |
   | `ADMIN_EMAIL` | بريدك لدخول لوحة التحكم |
   | `ADMIN_PASSWORD` | كلمة مرور قوية |
   | `NEXT_PUBLIC_SITE_URL` | رابط المتجر النهائي، مثل `https://marmouq.up.railway.app` |
   | `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | اختياري: لإشعار فوري بكل طلب |

4. **Settings** ← **Networking** ← **Generate Domain** للحصول على رابط المتجر، ثم ضعه في `NEXT_PUBLIC_SITE_URL`.
5. انتظر انتهاء النشر. عند أول تشغيل يُنشئ المتجر الجداول تلقائياً ويضيف منتجاتك الحالية وحساب المالك.
6. ادخل `/admin` بالبريد وكلمة المرور، ثم من **الإعدادات** أضف رقم الواتساب وحسابات التحويل.

> إعدادات البناء والتشغيل وفحص الصحة (`/api/health`) موجودة مسبقاً في `railway.json`، فلا تحتاج لتغيير شيء.

## دليل سريع للوحة التحكم

- **إضافة منتج:** المنتجات ← منتج جديد. اكتب الاسم والسعر، ثم أضف الألوان (مع درجة كل لون) والمقاسات، وحدّد الكمية لكل تركيبة. ارفع الصور واربط كل صورة بلونها ليتبدّل المعرض حين يختار العميل اللون. الصورة الأولى هي الغلاف.
- **إطلالة جديدة:** الإطلالات ← إطلالة جديدة. ارفع صورة الطقم، أضف القطع، ثم اختر كل قطعة واضغط على الصورة لوضع نقطتها، وحدّد نسبة الخصم.
- **دورة الطلب:** قيد المراجعة ← مؤكَّد ← قيد التجهيز ← تم الشحن ← تم التسليم. الإلغاء أو الإرجاع يعيد القطع للمخزون تلقائياً.
- **نصيحة للصور:** صوّر على خلفية فاتحة موحّدة وبإضاءة نهار ناعمة وبنسبة 4:5 (عمودية). المتجر يعالج كل صورة تلقائياً ويعرضها بإطار استوديو موحّد.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local      # عدّل DATABASE_URL وبيانات المالك
npm run db:migrate              # الجداول + حساب المالك + المنتجات
npm run db:seed -- --force --demo   # اختياري: بيانات تجريبية مع طلبات وهمية
npm run dev
```

## النسخ الاحتياطي
من خدمة PostgreSQL في Railway ← **Backups**، أو عبر `pg_dump "$DATABASE_URL" > backup.sql`. الصور جزء من قاعدة البيانات، فالنسخة تشملها.

### English (short)

Custom Next.js 16 + PostgreSQL storefront and admin back office for the MARMOUQ menswear brand. Deploy on Railway: create a project from this repo, add PostgreSQL, set `DATABASE_URL=${{Postgres.DATABASE_URL}}`, `AUTH_SECRET`, `ADMIN_EMAIL`, `ADMIN_PASSWORD` and `NEXT_PUBLIC_SITE_URL`, then generate a domain. Migrations, the owner account and the initial catalogue are applied automatically on boot (`scripts/migrate.mjs`). Admin lives at `/admin`.
